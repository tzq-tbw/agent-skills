# 备考助手 · 轻量版

从自己的课件、作业、答案和真题开始，按章节学习、刷题、记录错题，并把已有笔记整理成考前小抄。适合希望直接进入学习、不先配置完整建库流程的用户。

## 能做什么

- 按课程章节讲解，引用材料文件与页码，并展示相关题图。
- 从材料题练习、对照参考答案判分，记录答对、答错或跳过。
- 持续保存章节进度、概念疑问和错题，跨会话继续学习。
- 按需根据历年卷制作 AI 模拟卷，或整理章节学习讲义；这两条路线独立于普通学习状态。

## 使用

把整个 `universal-exam-cram-coach` 目录安装到 Agent 的技能目录。需要 Python 3.8+；PDF 提取和裁图按需使用 `pypdfium2`。安装步骤见[仓库说明](../../README.md)。

```text
使用 $universal-exam-cram-coach。
资料在【课程目录】，还有 3 天考试。先列出章节，再讲第一章；讲完后用资料里的题练习。
```

继续已有课程时，告诉 Agent 实际学习工作区，避免不同课程串用状态。可直接检查命令入口：

```powershell
python coach.py help
python coach.py status --workspace '<学习工作区>'
```

从本 Skill 目录执行命令，或把 `coach.py` 换成绝对路径。无需为了开始学习而手写题库 JSON。

## 输出

带来源的分章讲解、练习与判分结果、持久学习进度、错题和笔记，以及按需生成的 Markdown 小抄。模拟卷和学习讲义的输出由各自流程决定。

资料中的事实、AI 补充和 AI 推导会分别标记。题目没有参考答案时会说明，不把推导结果冒充教材答案。

## 限制

普通学习流程不把学生手写作答或扫描件自动当作官方答案。扫描教材等材料应按学习讲义路线逐页处理。材料提取失败时需要人工核对，不能保证所有 PDF、Office 文件都能直接解析。

核心 Python 工具不配置模型 API；实际讲解由宿主 Agent 完成。PDF 裁图成功和文档导出成功，也不等于教学内容已被完整核验。
