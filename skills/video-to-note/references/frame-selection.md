# 按章节与信息变化选取关键画面

固定间隔采样用于定位，最终截图由信息价值决定。不能用每章一张、每分钟一张或截图数量代替完整检查。

## 分段

- 有平台章节、自带章节或作者明确时间点时，按相邻分段点读取字幕/转录和画面，并检查边界前后约5秒。
- 获取不到章节时，结合完整文本的主题/步骤转换，以及标题页、页面切换和演示任务变化建立临时分段。说明“分析者划分”，不能把接口未返回章节说成视频没有章节。
- 无可用文本时，先以画面变化和稀疏缩略图定位，再逐段读取。每段可以多图或无图，按信息决定。

## 候选取并集

1. 正文区域变化：新页面、列表展开、步骤出现、配置改变和操作结果。排除表情、鼠标、弹幕和纯字幕变化；布局变化时重新确定正文区域。
2. 文本时间点：工具清单、具体步骤、提示词、公式、数字、关键例子、结果与结论，检查讲解时间点前后的画面。
3. 间隔巡检：先每15—30秒取缩略图定位；快切页面、密集步骤或短暂信息缩短间隔，检查该范围内的变化点。

三者取并集。变化检测可能漏掉小范围文字更新，所以不能替代文本定位和逐章检查。定位缩略图不全部进入笔记。

## 信息选择

优先保留工具/资源/配置清单、流程和操作步骤、可复用提示词/代码、设置位置、操作结果、公式图表对比和能说明用法的例子。

- 渐进展开的页面，最终版本包含前面全部信息时选完整版本；中间步骤有独有信息则另保留。
- 相似画面新增关键内容时不能去重；真正重复、纯口述或装饰可以跳过，并记理由。
- 在候选点附近选择动画结束、内容展开、文字可读且遮挡较少的稳定帧。必要时获取更清晰的视频流。
- 裁切保留理解所需的标题、坐标轴、图例、单位和上下文；复杂页面可以全图加局部图。
- 放大不能恢复细节。仍无法辨认的名称/数值/公式应记录缺口，不猜测。

## 漏图检查与保存

逐节对照笔记中的清单、步骤、配置、例子、公式、图表和结果，确认对应重要画面已保留，或记录具体未保留理由。

保存截图清单：所属章节、时间点、图片路径、承载信息、对应笔记位置。截图存入持久附件目录，笔记注明时间和说明；证据 JSON 的 key_details 和 attachments 同时引用这些截图。

不能用一张概览图代表整章操作已经核对。章节范围完整、重要信息清单和截图清单已对照，且实际可读的证据满足内容核对后，才进入成功清理。
