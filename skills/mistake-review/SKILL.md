# 错题整理与分析 · 互动复习

模式 A 整理归档，模式 B 互动复习；只执行用户要求的模式。模式 C 暂不启用，只有数据兼容说明，见 [references/mode-c.md](references/mode-c.md)。

## 资料与错题库

采用用户本次指定或当前会话已确认的错题库；缺少位置时再询问，不使用开发者的本机路径作为默认值。学科、章节、小节使用用户给定的名称，自动建立缺失目录，不猜教材编号，不按题面擅自重新分类。一次跨小节材料分别整理。目录为 `学科/章节/小节/`；每个小节一份 `错题分析.md`、`错题分析.pdf`、`复习记录.json`，并保留 `错题分析.tex` 便于检查排版。原材料可存放在小节 `assets/`。没有题目的小节不生成空文档。

当前模板为 A4 纵向、题目与解析分区、每题后留重做空白，LaTeX 排版。读库根 `排版设置.json` 复用已确认偏好；新库首次生成 PDF 时确认偏好。用户可随时调整。

## 模式 A：整理、分析与确认归档

1. 读取本次材料和指定小节的已有 Markdown、复习记录。图片需要实际看图；先确认方向、积分限、指数、导数阶数和适用条件。文字 PDF 可提取，但涉及公式时须看原页；扫描 PDF 先渲染再识别。保留文件路径、SHA256、页码/题号。关键符号不清楚时停在预览并询问，不补造条件。只处理明确指定的题，不将照片背景的其他题当作输入。
2. 每题提供完整原题、核心知识点、解题思路、详细解答、易错点与错因、方法总结。自行验证计算/证明；不得照抄图片解答并宣称验证。无个人错误过程时，实际错因标为“待确认”，与常见易错点分开。题号稳定；同题不同截图或相同原文先核对重复。
3. 按 [references/operations.md](references/operations.md) 写结构化批次 JSON，执行 `prepare`。预览存放在库外工作目录；不能提前写正式小节或最终 PDF。展示新增分析和受影响内容，等用户审校；修改仅限受影响的题。
4. 用户明确确认该预览或表示可以正式交付后执行 `archive --confirmed`。此开关只表示代理已收到人类确认，不能代替确认。仅要求测试时使用隔离测试库；用户随后确认正式交付时，归档确认版本，不复制模拟掌握状态。先生成并检查候选 PDF，再提交三份数据和 LaTeX；旧文件自动备份。脚本检测预览后库发生改变时拒绝归档，应重新合并预览。编译失败时保留原库与草稿。
5. 渲染 PDF，检查中文、公式、积分上下限、分式、页面边界和留白；提取文字检查题目齐全。PDF 与 Markdown 来自同一确认正文，但仍需视觉检查。新增题目只追加对应小节、不重解旧题；章节索引如需建立只加小节链接，不合并整章正文。

Python 工具负责文件与状态，识别、解题和教学由当前代理完成；工具不声称内置 OCR 或自动数学正确性判断。依赖 Python 3、`pypdf`、Tectonic（或 XeLaTeX）；路径和命令见操作文档。缺依赖如实报告，不生成假 PDF。

## 配图规则

涉及积分区域、参数曲线、几何关系或图形有助理解时，主动重画清晰示意图，不只贴原图。图中标注坐标轴、边界、范围、关键点及必要的截线/对称轴；曲线与参数范围必须符合题设，不凭示意图增添题设条件。推荐用 TikZ 生成矢量 PDF，并导出 PNG 供 Obsidian 显示，批次 `diagram` 字段传入。PDF 图形放在解析的解题思路后；不把答案放进题目区，不为纯符号证明硬加装饰图。图形也纳入预览、附件哈希检查和归档备份，复习时继续复用。交付前核对区域填充、边界、标注与解答一致，并查看图文排版；补图不能改变题号或复习历史。

## 模式 B：逐问复习与间隔记录

读相关小节 `错题分析.md` 和 `复习记录.json`，不重新读图、解旧题或生成 PDF。用户可指定小节、知识点、低掌握题或到期题；未指定时用 `due` 列出到期题再选择。未复习题为 `unreviewed`，不能凭导入标成 L0。

每次只问一个主要问题并等待回答，按知识条件 → 选方法及理由 → 关键推导递进。回答错误时先给提示，再根据需要逐步增加；用户要求才显示完整解答。不能凭最终答案正确就给高等级。一次完整复习后才写 `review`，记录问题、回答摘要、提示次数、判断依据；不记录未发生的复习或无意义长对话。

等级与初始间隔：L0 完全不会 1 天，L1 较多提示 3 天，L2 基本掌握 7 天，L3 独立完成 14 天，L4 连续独立熟练 30 天。L4 要求已有独立完成记录及本次无提示完成；实际间隔可由用户调整。使用用户所在时区的日期，不假定主机时区。普通复习更新不用逐次确认，但不得修改题目解答、PDF 或其他题的复习历史。

## 验证与交付

脚本自检用 `python scripts/test_workflow.py`，测试目录自动清理。真实材料的模拟归档与模拟复习放在库外独立的“测试验证”路径，测试记录明确标记 simulated，不能冒充学习情况。报告区分脚本检查、真实图片识别、数学验证、PDF视觉验收和真实用户复习；未验证项不得声称通过。

本 Skill 兼容图片、扫描页、PDF、文字来源；首次 PDF 排版以用户明确偏好为准，已确认偏好后复用。
