# 错题整理、分析与互动复习

把指定小节的图片、扫描页、PDF 或文字错题整理成有来源的分析，预览确认后归档；之后基于已有分析逐问复习，记录掌握等级和下一次复习日期。

## 两种使用方式

| 模式 | 你提供什么 | 得到什么 |
|---|---|---|
| A：整理归档 | 本次错题材料、学科、章节、小节及错题库位置 | 原题、知识点、思路、详细解答、错因与方法总结，先预览，确认后存入正式库 |
| B：互动复习 | 已有错题库，可指定小节、知识点、低掌握题或到期题 | 一次一个问题，按回答逐步提示，完成后保存本次复习记录 |

统计模式 C 暂未启用，不将保留的数据接口介绍为已实现的统计功能。

## 使用示例

```text
使用 $mistake-review。
把这些错题整理到【学科／章节／小节】，库放在【错题库目录】。
先给分析预览，我确认后再归档。
```

复习已有错题：

```text
使用 $mistake-review 复习【小节目录】的到期错题。
一次只问一个主要问题，先不要给完整答案。
```

## 安装与依赖

把整个 `mistake-review` 目录复制到 Agent 的技能目录，步骤见[仓库说明](../../README.md)。本公开草稿使用用户提供的库路径，不包含开发者的本机默认路径或个人错题。

需要可用的 Python 3，建议 Python 3.10+；PDF 检查需要 `pypdf`，生成 PDF 使用 Tectonic 或 XeLaTeX；页面视觉检查需要 PDF 渲染工具。此包不附带编译器二进制，安装到 PATH 或通过 `--compiler` 指定实际路径。具体操作见[工具说明](references/operations.md)。

## 归档结构

```text
学科/章节/小节/
├── 错题分析.md
├── 错题分析.pdf
├── 错题分析.tex
├── 复习记录.json
└── assets/           # 原材料与必要配图
```

错题分析与复习记录分开保存。题号稳定，追加新题时保留旧题和复习历史。预览位于正式库外，未确认时不写正式小节或最终 PDF。

## 重要行为

- 图片与公式需实际核对；看不清关键符号时停在预览，不补造条件。
- 没有个人作答过程时，把实际错因标为待确认，和常见易错点分开。
- 正式归档需要用户明确确认；`--confirmed` 只是工具标记，不能代替人的确认。
- 互动复习基于已归档分析，不重新解旧题或生成 PDF；完整复习后才记录等级。
- 无提示独立完成及历史记录是高等级的依据，不能仅凭最终答案正确就标为熟练。
